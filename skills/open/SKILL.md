# Stunt Double Studio: open

`/stuntdouble:open`, one of the Studio skills (`/stuntdouble:setup`, `/stuntdouble:run`, `/stuntdouble:open`, `/stuntdouble:cloud` and `/stuntdouble:doctor`). The `local` server ships only in the Claude Code plugin. Where its tools are missing, use the cloud skills.

`open_ui()` and print the link. Someone without Claude Code runs `npx stuntdouble view` in the project folder.
